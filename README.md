# zapisavto.github.io

Короткие ссылки на приложения онлайн-записи: `https://zapisavto.github.io/<студия>/` → приложение.
Страницы не индексируются (`noindex`). Корень пустой.

- Список студий: `tools/slugs.txt` (добавить строку → страница соберётся сама).
- Куда ведут ссылки: строка `TARGET` в `tools/build.mjs` — при переезде меняется только она.
- Сборка: Actions → «Собрать переадресации».
